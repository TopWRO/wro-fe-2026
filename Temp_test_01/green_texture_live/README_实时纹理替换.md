# 单文件实时形状与绿色材质替换

只需复制 `green_texture_live.py` 到树莓派，使用能运行 Recording_N02.py 的同一个 Python 环境。不要升级或更换已验证的摄像头环境。程序直接依赖 OpenCV、NumPy、DonkeyCar 及已安装的相机后端，不依赖其他项目 Python 文件或额外材质图片。

先退出其他占用相机的程序，然后在树莓派桌面/VNC终端运行：

```bash
python3 green_texture_live.py
```

## 实时行为

摄像头采集 640×480，DonkeyCar 相机后台线程，处理循环目标 20 Hz，实际速度取决于树莓派性能。严格沿用已恢复正常颜色的相机属性设置顺序：30 fps、曝光模式 off、AWB 模式 off、ISO 100、快门 15000 μs、曝光补偿 0、白平衡增益 (1.2, 1.5)。不新增 Picamera2 set_controls() 强制曝光/增益/白平衡设置。

显示两个干净画面：原始图像、替换后的图像。每帧都从原图识别红色，再判断旋转包围框宽÷高。标准红柱保留，瘦高/矮红柱被替换为参考绿柱的真实纹理，保持目标原有轮廓。已有绿柱不替换。不会把已替换的输出反馈进下一帧检测。

默认参考材质直接内嵌在文件中，来自用户已认可照片里的第三根真实绿色柱子。因此画面里没有绿柱，也能进行替换；不是用纯亮绿色填充。

当前固定视角测试阈值：

| 旋转框 W/H | 判定与处理 |
| --- | --- |
| 0.20～低于 0.44 | 瘦高，贴绿柱纹理 |
| 0.44～0.60 | 标准，保持原图 |
| 高于 0.60～1.60 | 矮，贴绿柱纹理 |
| 范围外或接触图像边缘 | 不确定，保持原图 |

它们不是任意角度、距离下通用的物理高度阈值。没有跨帧跟踪或时间平滑，阈值附近可能出现判定跳变。背景红色物体也可能被当作候选柱子。

## 按键

先点击替换后窗口，使其获得键盘焦点：

- **S / s**：保存本帧原图、干净换色图、替换掩膜、标注调试图、当前参考材质和 JSON 到程序旁的 captures。
- **R / r**：从当前原始画面采样面积最大的完整绿色物体作为新材质。操作时确保画面里最明显的绿色物体就是真实绿柱；不要出现更大的绿色背景。找不到合适目标时保留原参考，不会终止程序。材质一旦采样就固定使用，直到下次按 R 或重启。
- **D / d**：开启/关闭轮廓、比例、判定调试窗口。
- **Q / Esc / Ctrl+C**：退出并释放相机。

`_converted.png` 是没有文字和框线的替换图；`_raw.png` 是原图。`_debug.png` 是另存的标注图。当前只是图像预处理预览，尚未控制电机或接入 AI 模型。

## 暗红边缘改进

形状检测仍使用原来的红色阈值，避免因放宽识别而改变分类。替换范围则分为两部分：

1. 对需要替换的目标，填满已检测到的轮廓，包括轮廓内部的很暗区域或小孔洞。
2. 在该轮廓外最多 2 像素内，额外覆盖满足宽松暗红条件的像素：S≥40，V≥15，以及扩大的红色色相范围和通道红色约束。

不会无条件扩大整个矩形。标准柱/不确定目标的轮廓区域受保护。纯黑、完全失去红色信息的外部阴影不盲目覆盖；附近颜色相似的背景仍可能被纳入，可缩小边缘半径。

如果仍有红边：

```bash
python3 green_texture_live.py --edge-pixels 3
```

更暗边缘可试：

```bash
python3 green_texture_live.py --edge-pixels 3 --edge-v-min 10
```

边缘扩展允许 0～6 像素；`--edge-pixels 0` 用于对照关闭外部扩边。建议从默认 2 开始，放大太多会增加背景误覆盖。

## 其他参数

```bash
python3 green_texture_live.py --normal-min 0.44 --normal-max 0.60 --debug
python3 green_texture_live.py --reference-image full_photo_with_green_pillar.png
python3 green_texture_live.py --image original.png --no-window
```

`--reference-image` 需要包含完整绿柱的普通照片（四周留出背景），不是紧贴边界的透明材质抠图。未指定就用内嵌参考。

`--image` 是不用摄像头的照片测试入口，自动保存结果；`--no-window` 只用于照片测试。现场实时显示需要桌面/VNC。
