# 平均边长实验版与后续采样评估

## 使用单文件平均边长版

```bash
python3 green_texture_live_average.py --debug
```

默认不混用上一版的柱底双面辅助判定，而是使用本次要求的平均边长方法。仍保留原来的相机设置、内嵌真实绿色纹理、暗红扩边以及 S/R/D/Q 操作。它是测量和对照实验版，实测不能仅凭这个比例可靠区分所有高柱与标准柱。

按 D 显示四角拟合和测量值。按 S 保存 JSON，包含：

- edge_top_width_px / edge_bottom_width_px：上、下边长度。
- edge_left_height_px / edge_right_height_px：左、右边长度。
- average_width_px / average_height_px：平均宽、高。
- average_w_over_h / average_h_over_w：两种方向的比例。
- quad_fit_fraction：四边形面积占轮廓凸包面积的比例，供观察拟合质量；不是模型置信度。

四个角依次为左上 A、右上 B、右下 C、左下 D，按图像内目标方向排序：

```text
W_top = distance(A,B)       W_bottom = distance(D,C)
H_left = distance(A,D)      H_right = distance(B,C)
W_average = (W_top + W_bottom) / 2
H_average = (H_left + H_right) / 2
ratio = W_average / H_average
```

距离是边的像素长度，能容忍一定图像内倾斜；不是水平包围框的 x 跨度。也没有先把图形透视拉成规定尺寸再测量，以免把预设比例当成测量结果。

从实际红色轮廓的凸包简化顶点中选最大面积的内接四边形，不是对最小包围矩形取平均。包围矩形的对边原本相等，取平均没有意义。如果斜看出现五/六边形，这四个角只是外轮廓近似，并不保证等于某一个真实侧面的四角。拟合不足、比例无效、目标被画面截断时保持原色。

对照原始旋转包围框算法：

```bash
python3 green_texture_live_average.py --measurement box --debug
```

默认标准区间仍为 0.44～0.60，可用 --normal-min / --normal-max 调整；当前样本存在比例重叠，没有据此宣布得到通用新阈值。

## 现有照片的结果

对 captures 目录里的 8 张近景原图：

- 高柱平均边长 W/H 约 0.533～0.571。
- 标准柱平均边长 W/H 约 0.480～0.533。
- 矮柱平均边长 W/H 约 0.999～1.120。

高柱和标准柱仍然重叠；部分高柱按默认标准区间仍会保留红色。这是实际测量结果，不是已修好的最终分类规则。当前四边形选择也可能随轮廓小变化改变，需观察黄色四边形是否合理。

已用已知梯形验证上边 100、下边 60 的平均宽为 80，左右边约 201 的平均高约 201；并测试图像内旋转、真实照片、输入及改动范围外像素不变、模拟实时显示与按键保存。尚未测试真实树莓派实时速度。

## 关于后续 5 fps 采样和训练（本次未开始实现或训练）

方案可行。建议每类先拍 200～300 张作首轮数据，总计约 600～900 张，但有效的视角和距离多样性比总张数更重要。5 fps 下每类只需约 40～60 秒就能凑够张数，连续相邻帧可能高度相似；应分多段刻意改变距离、侧角、画面中央/边缘位置、俯仰和光线。

每次只放一个已知高度的目标，标注 5 cm / 10 cm / 15 cm 和拍摄段编号，保留完整原图，必要时另存红色掩膜与目标裁剪。固定实际车载相机安装位置及颜色设置。分类目标要完整可见，截断/严重遮挡另设 unknown 样本。

裁剪缩放应保持原长宽比并补边，不要把三种柱子分别直接拉伸成同样的正方形，否则会主动丢掉要学习的形状信息。相同外观、不同位置与背景都应覆盖，避免模型只记住“左边就是高柱”或特定背景。

我建议首先尝试多个几何特征的轻量分类器（例如小决策树），输入可以包括平均比例、上下宽度之比、左右高度之比、轮廓填充率和底部形状。需要时才比较小型图像分类网络。固定一个比例阈值是只有一个特征的特例，数据可能表明需要多特征组合而不是一条通用公式。

训练/验证应按不同拍摄段分组分开，而不是把相邻帧随机分散。评估时单独报告标准柱被误换的比例、高柱/矮柱漏换比例，并保留无法确定时不换色的出口。几百张照片可用于验证方案是否有希望，不能保证覆盖任意角度，更不能从视觉信息本身已经不可区分的图像中保证恢复真实高度。

另一个独立改进是棋盘格相机标定和去畸变；它可针对镜头畸变，但不能单独消除所有三维透视差异。
