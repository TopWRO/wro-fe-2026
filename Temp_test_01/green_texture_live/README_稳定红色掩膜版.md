# 稳定红色掩膜与纹理替换版（单个 Python 文件）

```bash
python3 green_texture_live_stable.py --debug
```

只复制这个 .py 到树莓派即可，使用能运行原 Recording_N02.py 的 Python 环境。保持已验证的摄像头设置，640×480 取图、20 Hz 目标循环，实际速度取决于树莓派。内嵌已认可的真实绿柱纹理，不需要额外材质图片。

## 本次针对的问题

目标是减少红柱掩膜在阴影、边缘和轻微移动时反复出现/消失，以及同一柱子在阈值附近反复换色。它不是经过训练的高度分类模型，也没有 99% 准确率验证。

### 颜色掩膜

1. 明确的红色作为种子：默认沿用 H 0～10 / 170～179、S≥100、V≥70。
2. 在种子附近允许更暗的红色：默认 H 0～15 / 165～179、S≥55、V≥10，并检查红通道相对绿/蓝通道的优势，避免把绿柱或普通黑白背景算作红色。
3. 每个明确红色区域最多向外搜索 4 像素，连通的暗红区域可以补入；不允许沿黑条纹/木边无界扩散。
4. 已跟踪目标的历史掩膜可帮助保留暗下来的区域，但必须仍有当前画面的弱红色支持；历史区域不会逐帧无限扩大。
5. 目标内部小孔洞直接填满，避免高光/暗点在材质贴合后留下红色闪点。

不能简单把整幅图中所有“非黑非白”像素当红色，因为仍有原绿柱，画面边缘还可能出现木边、收纳盒等。这里利用黑白背景的高对比度，但仍要求红色联系。

形状测量使用明确红色核心的轮廓；用于连续覆盖的掩膜可以更宽，避免补阴影把宽高比也拉偏。

### 时间稳定

- 按空间重叠、位置及尺寸关联目标，保留 track_id；不会仅按左、中、右位置编号记忆类别。
- 掩膜历史随目标位置对齐，采用时间平滑和进入/退出的不同阈值；小于 2 像素的位置变化设死区，减少轮廓毛刺使整块掩膜跳动。
- 已有像素可以保留；新出现的边缘通常需要连续支持，单帧凸出噪点不立即加入。
- 类别比例取最近 7 个可用完整观测的中值，并加入 0.025 滞回带。改变已跟踪类别默认需要 5 次连续支持，因此有响应延迟，不是每帧独立判断。
- 目标触及图像边缘不再一律跳过。有历史类别时，部分截断期间保持该类别；首次就只看到一部分时，按可见比例给出暂定判断。如果比例本身无效，仍不能知道真实高度。
- 目标完全消失时不画历史材质，避免在背景留下绿色拖影；6 帧未匹配后删除记忆。

掩膜稳定与高度分类准确是两回事：如果初始类别判错，稳定机制也可能暂时保留错误类别。目标交叉、合并、大幅跳动时可能关联错误；这些需要真实视频验证。

## 实时窗口与按键

点击替换结果窗口后：

- S：保存原图、干净替换图、替换掩膜、调试图、参考材质和 JSON。
- R：从当前原图中采样真实绿柱材质，固定使用到下一次 R。
- D：开关形状调试和 **Stable red foreground mask** 窗口。后者白色表示稳定的红色目标区域，黑色表示背景，便于观察是否还在抖动。
- C：清空跟踪/类别记忆，下一帧重新判断。可在更换测试柱子、目标身份关联不对时使用。
- Q / Esc / Ctrl+C：退出并释放相机。

_converted.png 是无文字框线的图像。JSON 记录 raw_decision、最终 decision、track_id、filtered_ratio、pending_votes、decision_held 等信息。

## 形状判断模式

默认 hybrid：底部双面几何清楚时使用该辅助比，否则用平均边长，四边形不可靠时回退旋转包围框。标准区间默认 0.44～0.60。可比较：

```bash
python3 green_texture_live_stable.py --measurement average --debug
python3 green_texture_live_stable.py --measurement box --debug
```

对已有标准类别，0.44 下限加 0.025 滞回后，需要过滤比例低于约 0.415 并连续满足确认次数才转为高柱；上限同理。首次看到目标仍按基础阈值暂定。此差异是有意防止边界反复切换。

## 可调参数

```bash
# 暗红边缘仍缺失：略加大目标附近的补全范围。
python3 green_texture_live_stable.py --grow-pixels 6 --debug

# 只针对很暗、仍然带红色的部分降低亮度要求。
python3 green_texture_live_stable.py --weak-v-min 6 --debug

# 更不容易改变已记住的类别，但切换会更慢。
python3 green_texture_live_stable.py --switch-frames 8
```

不要一次将所有颜色阈值大幅放宽；额外背景可能被纳入。--grow-pixels 允许 0～12，默认 4。--weak-s-min 默认 55，--weak-v-min 默认 10。

--normal-min / --normal-max 仍可调整基础标准区间。--hysteresis 控制滞回宽度，默认 0.025；设为 0 可对照关闭滞回，但仍保留中值和连续确认。

## 已做的测试

- 8 张现有实拍图：高柱替换、标准柱保留、矮柱替换，细长背景碎片不凭空判成柱高。
- 合成亮暗连续帧：旧式红色阈值的掩膜面积在约 16500 与 29900 像素间变化；新版在该测试中保持目标面积 30000 像素，包括内部孔洞覆盖。
- 整根目标连续暗下来的合成序列：借助历史和当前弱红色仍能保持覆盖。
- 比例在阈值附近波动：不反复换类；持续支持新类别后可切换。
- 单帧边缘凸出：实际输出不立即换色覆盖；持续出现后才纳入。
- 移动、消失、记忆到期：不将旧目标贴在已变成背景的位置。
- 首次顶部截断：允许可见形状暂定分类；已记住的标准柱被部分截断时仍保留标准类别。
- 模拟相机的保存、采样、清空记忆、调试开关及退出流程通过。

上述连续帧是模拟扰动，不是真实行驶视频。静态照片不能证明实际抗抖效果、实时帧率或 99% 准确率。未开始训练模型。

严重截断、完全无颜色信息的黑影、目标太小、遮挡、相似轮廓，仍可能让单目图像无法可靠区分真实高度。建议先看本版稳定掩膜窗口并拍一段真实移动测试视频，再决定是否进入多角度数据采集与模型训练。
